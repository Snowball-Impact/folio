# Power BI Learning Programs

Power BI 공식/커리큘럼형 학습 플레이리스트 수집 결과입니다.

정기 운영에서는 통합 명령을 사용합니다.

```powershell
python tools\collect_powerbi_all.py
```

개별 갱신이 필요할 때는 아래 명령을 사용합니다.

```powershell
python tools\collect_powerbi_learning_videos.py
```

`Power BI > 학습 콘텐츠`의 공식 학습/한국 크리에이터 탭 상단 프로그램 카드로 사용됩니다.
