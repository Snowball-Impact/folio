# Streamlit Documents

Streamlit 원본 구현의 과거 실행·배포·통합 검증 기록이다. 현재 운영 기준은 SvelteKit + Cloudflare Pages이며, Streamlit 원본 소스는 로컬 백업 zip(`archive/streamlit_app_20260909.zip`)에 보관한다.

- [PAAS_DEPLOYMENT.md](PAAS_DEPLOYMENT.md): Docker 기반 PaaS 운영 과거 계획
- [STREAMLIT_CLOUD_DEPLOYMENT.md](STREAMLIT_CLOUD_DEPLOYMENT.md): Streamlit Community Cloud 과거 기록
- [INTEGRATION_VALIDATION.md](INTEGRATION_VALIDATION.md): Streamlit 기준 실제 Supabase 검증 과거 기록

이 폴더의 문서는 historical record다. 제품과 데이터의 현재 기준은 `../common/`, SvelteKit 현재 실행·배포 기준은 `../svelte/`, 이전 증거는 `../migration/`을 참고한다.
