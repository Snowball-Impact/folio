# 서비스 소개 페이지 와이어프레임

목표: FOLIO의 목적과 출발점을 짧고 선명하게 설명한다. 홈 갤러리의 정돈된 라이트 UI를 기준으로 하며, 과한 랜딩페이지 연출보다 제품 이해와 등록 CTA에 집중한다.

## 네비게이션

```text
┌──────────────────────────────────────────────────────────────┐
│ Folio                         홈 갤러리  서비스 소개  프로젝트 등록  마이 페이지 │
└──────────────────────────────────────────────────────────────┘
```

- 새 메뉴 라벨: `서비스 소개`
- 위치: `홈 갤러리`와 `프로젝트 등록` 사이
- 현재 페이지 underline 적용

## 1. Hero: FOLIO 브랜드 카피

```text
┌──────────────────────────────────────────────────────────────┐
│ [경기청년 갭이어 가로 배너 full width]                         │
├──────────────────────────────────────────────────────────────┤
│ 경기청년 갭이어 2026의 지원을 받아 시작했습니다.                │
│ FOLIO는 경기도가 지원하는 경기청년 갭이어 2026 사업을 통해      │
│ 시작한 프로젝트입니다.                                          │
│                                                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

규칙:

- 히어로는 가로 배너 이미지를 full-width로 사용
- 카피는 이미지 아래 caption으로만 짧게 배치
- 별도 CTA는 두지 않음
- 모바일에서도 이미지는 유지하되 자연스럽게 축소

## 2. Snowball Impact 팀 소개

```text
┌──────────────────────────────────────────────────────────────┐
│ [팀 캐릭터 이미지 16:9]        작은 기록이 다음 프로젝트의 근거가 되도록 │
│                              Snowball Impact는 FOLIO를 만들고 있는 팀입니다. │
│                              서비스 MVP를 직접 구현하며 검증하는 단계입니다. │
│                              [Contact Us]                    │
└──────────────────────────────────────────────────────────────┘
```

규칙:

- 캐릭터 이미지는 브랜드 보조 비주얼로 사용
- 큰 hero 이미지로 쓰지 않음
- 회색 배경은 유지하되, 이미지 자체를 16:9 영역에 맞추고 과한 장식 없이 배치

## 3. FOLIO 소개: 이유와 할 수 있는 일

```text
┌──────────────────────────────────────────────────────────────┐
│ FOLIO는 프로젝트를 어떻게 남기나요?                           │
├──────────────────────────────────────────────────────────────┤
│ 01 RECORD        02 SHARE            03 GROW                  │
│ 맥락을 기록       공개하고 탐색        반응을 보고 개선          │
├──────────────────────────────────────────────────────────────┤
│ 프로젝트 등록 / 결과물 연결 / 갤러리 탐색 / 반응 확인 / 피드백 확장 / 관리 │
└──────────────────────────────────────────────────────────────┘
```

규칙:

- 카드 2개를 띄우지 않고, full-width section 안에서 row 단위로 정리
- 제목 왼쪽, 설명 오른쪽
- 구분선만 사용

## 4. VISION

```text
┌──────────────────────────────────────────────────────────────┐
│                         VISION                               │
├──────────────────────────────────────────────────────────────┤
│ [Snowball Impact 배경 이미지]                                  │
│ 눈덩이 1: Phase 1 Portfolio Platform                           │
│ 눈덩이 2: Phase 2 Community                                    │
│ 눈덩이 3: Phase 3 Best Practice Archive                        │
│ 눈덩이 4: Phase 4 Career Network                               │
│ Snowball Impact: 프로젝트를 모으고, 피드백을 연결하고,          │
│ 좋은 사례를 축적해 커리어 기회로 확장합니다.                    │
└──────────────────────────────────────────────────────────────┘
```

규칙:

- PRD의 Long-Term Vision을 4단계 로드맵으로 반영
- `질문 -> 피드백 -> 답변 -> 개선` 루프를 다음 단계의 핵심으로 설명
- 기능 나열보다 플랫폼이 커지는 방향을 보여준다

## 모바일 구조

```text
┌────────────────────┐
│ Folio              │
│ 홈 / 소개 / 등록    │
├────────────────────┤
│ 갭이어 배너 이미지 │
│ 지원 안내 caption  │
├────────────────────┤
│ Snowball Impact    │
│ 팀 캐릭터 이미지    │
├────────────────────┤
│ FOLIO 소개         │
│ RECORD/SHARE/GROW  │
├────────────────────┤
│ VISION             │
│ Snowball 도식       │
├────────────────────┤
└────────────────────┘
```

## 구현 메모

- 페이지 파일 후보: `folio_app/pages/about.py`
- 라우터 page key 후보: `About`
- nav 라벨: `서비스 소개`
- 스타일 후보: `folio_app/styles/about.py`
- 가능한 한 기존 `render_hero()`와 `--folio-*` 토큰 재사용
- 새 컴포넌트보다 `section`, `row`, `flow step` 중심으로 구성
