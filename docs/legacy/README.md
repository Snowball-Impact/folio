# Legacy Documents

이 폴더는 현재 작업 기준으로는 자주 보지 않는 초안과 완료 기록을 보관한다.

## 포함 문서

| 문서 | 성격 |
|---|---|
| `WIREFRAME.MD` | 이전 화면 구조 와이어프레임 |
| `SERVICE_INTRO_WIREFRAME.md` | 서비스 소개 페이지 구현 전 시안 기록 |
| `PROJECT_DETAIL_PAGE_IMPROVEMENTS.md` | 프로젝트 상세 페이지 1차 개선 기록 |
| `BACKLOG_ISSUE_DRAFTS.md` | 기능정의서 기반 GitHub 이슈 초안 |
| `WEEK1_BUILD_CHECKLIST.md` | 1주차 완료 기록 |
| `WEEK2_BUILD_CHECKLIST.md` | 2주차 완료 기록 |
| `assets/` | 서비스 소개 시안용 이미지 복사본 |
| `개발 로드맵(4주).png` | 초기 로드맵 이미지 |
| `폴리오 와이어프레임_초안.png` | 초기 와이어프레임 이미지 |

현재 기준 문서는 상위 폴더의 `PROJECT_CONTEXT.md`, `ENGINEERING_PLAYBOOK.md`, `DESIGN_SYSTEM.md`를 우선한다.
